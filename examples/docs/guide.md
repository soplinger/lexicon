# Setup guide

Sign in to Github with your account before you open a pull-request.

The CLI talks to the API over HTTPS.

Set the default branch to the master branch, then push.

Keep whitelist entries in the config file.

The Command-line interface (CLI) reads the Application Programming Interface (API) key.

```bash
github login
```

Run `github` as-is inside inline code.
